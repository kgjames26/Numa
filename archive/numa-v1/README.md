# Numa — Budget en clair

Application PWA de gestion de budget individuel ou en couple. Revenus mutualisés ou séparés, charges récurrentes, historique des soldes et sauvegarde JSON.

## Déploiement Vercel

Importer ce dépôt dans Vercel. Framework : Other. Aucun build command requis. Output directory : racine du projet.

## Confidentialité

Les données sont stockées dans localStorage sur l'appareil. Aucun serveur et aucune synchronisation. Exporter régulièrement une sauvegarde JSON.

## Statut

Prototype initial, à tester avant diffusion publique. La version ne doit pas être considérée comme validée pour la production.
