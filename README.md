# NUMA

NUMA is a local-first, installable budgeting PWA. A new installation starts with an empty budget and a short setup flow. The application stores data in IndexedDB on the current browser/device; there is no account, bank connection, or cloud synchronization.

## Run locally

```sh
npm install
npm run dev
```

## Checks and production build

```sh
npm test
npm run build
npm run preview
npm run test:e2e
```

Deploy the generated `dist` directory to Vercel. `vercel.json` provides the SPA fallback. The service worker and manifest are generated by `vite-plugin-pwa`.

## Data and financial model

- Amounts are stored as integer cents.
- Recurring income and expenses are converted to monthly equivalents by the independent `src/finance.ts` engine.
- Expenses tagged as envelope-funded are excluded from planned expenses; their envelope allocation is counted once.
- Actual income and expenses are entered in Activity. Actuals are not inferred from forecasts.
- JSON export/import covers the full local state. CSV export covers ledger entries.
- Use JSON backup to move data between devices. Browser storage can be cleared by the operating system; keep a separate backup for durable retention.

## Current scope

The first release includes onboarding, personal/shared household mode selection, configurable income and expenses, envelope allocations, goals, ledger entries, monthly navigation, actual-versus-planned figures, six-month projections, dark mode, local backup/restore and offline app-shell caching. Multi-person contribution rules, recurring schedule instances, complete monthly snapshots, account reconciliation, goal withdrawals, advanced simulation controls and automated browser/device coverage are not yet implemented.

Financial projections are planning estimates, not bank balances or financial advice. A true cash balance requires importing or entering all relevant account movements.
